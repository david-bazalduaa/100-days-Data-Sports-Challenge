# Language Convention Standard

1. **Code & Technical Assets (Strictly English):**
   - All code, scripts, module names, function names, and variable names.
   - All Python docstrings (PEP 257 format), inline comments, and type hints.
   - All notebook markdown cell titles and headers that describe technical steps, schema, or code execution.
   - Git commit messages and pull request descriptions.

2. **Analysis, Reasoning & Chat Dialogue (Strictly Spanish):**
   - All conversational responses, senior guidance, mentorship, and architectural discussions.
   - Explanations of sports analytics concepts, tactical insights, decision trade-offs, and EDA interpretations.
   - Interactive feedback, questions, and daily challenge planning.
